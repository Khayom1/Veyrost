02 / VERIFICATION PRINCIPLES

Research must be inspectable.

We separate implemented features, experiments and roadmap items. A visual showcase is not proof that a service is live.

Source-backed statements

  • Link each product to its canonical GitHub repository.
  • Use README and repository metadata for project summaries.
  • Mark repositories with incomplete public documentation.

Release discipline

  • Run syntax and regression checks before merging.
  • Confirm Pages deployment after publishing.
  • Request real-device testing for camera, gesture and mobile interaction.
